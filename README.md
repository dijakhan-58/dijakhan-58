## <img src="https://media.giphy.com/media/iY8CRBdQXODJSCERIr/giphy.gif" width="30"> About Me

<img align="right" src="https://media1.giphy.com/media/v1.Y2lkPTc5MGI3NjExMXE0NTNlOG12anhpamVvbWhudWY2NHV2MGNoanl6emptdnF6bTBvNyZlcD12MV9pbnRlcm5hbF9naWZfYnlfaWQmY3Q9Zw/L1R1tvI9svkIWwpVYr/giphy.gif" width="200"/>

I'm a Full-Stack Web Developer from Karachi, working across both **frontend and backend**. On the backend I build with **Laravel, PHP, and MySQL/SQL**, and on the frontend I work with **JavaScript, Bootstrap, and Tailwind CSS** to put together responsive, usable interfaces.

I enjoy the full picture of a web app — designing the interface someone actually interacts with, and building the logic, database structure, and application flow behind it. Most of what I build revolves around practical, database-driven applications: CRUD systems, role-based access, and everyday tools that solve a real problem.

Right now I'm focused on strengthening my backend architecture skills and expanding into modern full-stack tools like React and Node.js.
